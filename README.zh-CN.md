# 文明 VI 群控：p2.7 自动等待与连续行军

构建20260923-p2.7。安装状态见HANDOFF.zh-CN.md，本轮测试步骤见TEST-p2.7.zh-CN.md。

## 剩余移动力自动等待

行军或协同进攻的本回合队列结束后，若任务尚未完成、仍有移动力却没有合法继续落点，自动调用原生“跳过本回合”，目标保留，下一回合自动继续。已到达或被手动接管的单位不自动跳过，不改成驻守/睡眠。不强改移动力；游戏拒绝时保留任务。p2.7新行为通过离线验证，仍待实机确认提示效果。

## 操作台与筛选

控制台分为选取、筛选、执行三个区域，诊断默认收起。带箭头的分类只浏览，点击“选用此类全部单位”才应用父类；末级直接应用。侦察位于战斗单位→陆军→侦察单位，与近战并列。军种、医疗支援、非战斗单位、建造者、开拓者、九类伟人分别可筛选。筛选不会自动全图选取，切换后需重新框选以加入新类别。

框选或双击屏幕内同兵种；Shift追加。右键只预览，确认按钮才下令。关闭群控、Esc、清除选择和筛选不停止已执行的任务；“停止全部命令”停止行军、协同进攻，并关闭自动交战。

## 协同进攻

右键已交战的可见城外敌军，点击“开始协同进攻”。任务锁定同一敌军身份，在当前游戏会话内跨回合继续。每回合重查可见目标位置和合法路径。目标死亡、失去视野、进入不支持的城市/外交情况时停止，不换目标、不自动宣战。

先执行当前位置合法的远程和近战攻击，再分配陆地接敌落点。队伍的可达前沿由最慢成员估算，快速单位一般不超过该前沿两格；已经有合法攻击机会的单位可先攻击。零移动力成员也参与前沿约束。落点按占位规则匹配，候选少的单位先执行；优先使用预先分配的落点。队首移动后，初始被堵的单位会在同回合补检查一次。每回合重新规划；连续三回合无推进且无直接攻击安排时停止并交回控制。

这是基于本机原生可达格和可见信息的协同策略，不是所有地形下的最优编队。实际行动仍受移动力、地形、射程和占位限制。没有本回合行动力的战斗队也可先安排下回合进攻。平民不参加进攻。明确手动接管的单位退出任务。

## 可选闲置自动交战

点击“自动交战：关”开启，初始默认关闭，读档后需重新开启。仅处理闲置、清醒的陆地战斗单位；当前原生选中、群控正在选择、睡眠/驻守、护送、当回合手动下令、行军/协同任务中的单位不接管。当前版本在任何群体行军或协同任务运行时整体让行，优先保证手动群控流畅。

只针对当前位置原生允许攻击的可见已交战军队。使用CombatManager.SimulateAttackInto的实际强度修正和伤害预测：预计能存活且留有至少10生命点或原生随机伤害余量、预计能造成伤害，并且预计击杀或强度差不低于-5且伤害交换差不低于-3时攻击。预测缺失或无法合法攻击就待命，不根据基础面板数值盲猜。

明显劣势时，在本回合可达、全程可见、自有或中立陆地中寻找更远离周边可见敌军攻击范围的位置；终点和路径都不能提高估算威胁。找不到就原地待命。避让依据局部可见敌军距离与射程，不保证下一回合绝对安全，也不评估未知伏兵。每单位每回合最多自动行动一次。扫描分批、限频；动作超时关闭自动交战。

## 普通行军与存档

空地目标仍使用持续行军。任务保存到当前游戏的玩家属性中，通过官方剧本同类EXECUTE_SCRIPT通路写入。p2.6改用明确clear动作清除记录，不依赖空字符串；使用GC_MarchV2新格式，不读取p2.5可能残留的旧记录。升级后首次需重新指定目标。

读档校验单位身份、位置和下令回合；存档时未确认的在途单位不重放。保存前等当前移动完成。真实存档恢复与清空仍需实测。协同进攻目前不跨读档恢复；仅普通持续行军有存档支持。

## 验证与范围

p2.6离线通过17集结、15分类、28攻击、30行军、25自动战术/协同场景，以及输入、双击、菜单、存档桥、11Lua语法和XML检查。新增行为尚未游戏实测；不能据模拟结果保证游戏体验。

海空完整接敌移动、城市攻击、链接护送、联机仍未适配。普通行军仍限陆地，复杂迷雾和动态占位需要更广实测。
